As we stated the norm is a definition that models length. Why the particular rules we stated?


1. Positive definiteness<br>
Length should be $\geq 0$, and we want the only vector that has zero  length to be the additive identity $\mathbf{0}$.
2. Absolute scaling<br>
It is sensible if we scale a vector the length is scaled accordingly but not with sign<br>
3. Triangle Equality<br>
This is based the intuition that if we walk to one point and from that point walk to another point it should be shorter or equal to walk directly.
